# Chapterlet book format, version 1

A portable book is UTF-8 JSON with no internal identifiers or personal annotations. See the [machine-readable JSON Schema](book.schema.json) and [original complete example](../public/examples/a-small-art-of-attention.json).

| Field                   | Contract                                                                                                                            |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `schemaVersion`         | Required integer literal `1`; other versions are rejected with an explanation                                                       |
| `title`, `author`       | Required non-blank strings, trimmed, at most 1,000 characters                                                                       |
| `chapters`              | Required ordered array, 1–1,000 chapters                                                                                            |
| `chapters[].title`      | Required non-blank string, at most 1,000 characters                                                                                 |
| `chapters[].paragraphs` | Required ordered array, 1–10,000 non-blank strings per chapter, at most 100,000 characters each                                     |
| `description`           | Optional string, at most 20,000 characters                                                                                          |
| `kind`                  | Optional `summary`, `abridgement`, or `notes`                                                                                       |
| `language`              | Optional language tag such as `en`, `en-GB`, or `zh-Hant`; syntactic validation, not registry validation                            |
| `tags`                  | Optional array of up to 100 non-blank strings                                                                                       |
| `coverImageDataUrl`     | Optional base64 PNG, JPEG, or WebP data URL, at most 3 MB decoded; signature and decode checked, under 40 MP and 16,000 px per side |

Unknown properties are rejected at every object level. The book file or pasted UTF-8 text must not exceed 20 MB. Empty or whitespace-only paragraphs are invalid. Paragraph whitespace, Unicode punctuation, emoji, and newlines are preserved. Metadata titles/authors/chapter titles are trimmed. UUIDs are generated only when importing.

## Inline grammar

- `**important**` → bold.
- `*thoughtful*` → italic.
- `` `a short code phrase` `` → inline code.
- `[label](https://example.org)` → an external link opened deliberately in a new tab, with `noopener noreferrer`.

Absolute `https:`, `http:`, and `mailto:` are allowed. Relative URLs and other schemes are literal text. HTML is always escaped by React; images, blocks, tables, arbitrary HTML, and full CommonMark nesting/escaping are not supported. The parser bounds recursive nesting. The exact rendered text is also the source of annotation offsets and search text.

## Import and export

Select a local `.json` file or paste JSON. Preview the title, author, description, chapter list, and estimated reading time (220 words/minute). Add the book only when satisfied. Normalised title and author identify likely duplicates; keeping another copy requires an explicit choice. There is no content replacement operation, so existing annotations cannot be silently invalidated.

Export from Book Details produces this same public format, including a local cover if present. It strips internal IDs, database timestamps, reading progress, and all personal annotations. Export/import therefore creates a new independent book. Full backups preserve identity and reading data.

## AI prompt

The [complete prompt](ai-generation-prompt.txt) and JSON Schema are generated by `npm run docs:generate` from `src/schemas/book.ts`, which also supplies the copy actions in the app. Zod custom image-signature refinements cannot be fully expressed in JSON Schema; the textual image restrictions above still apply. The prompt avoids images to keep external model output simple.

The external model must return valid JSON only, with no Markdown fences, and correctly escape quotation marks and special characters. Chapterlet never sends your material to an AI service.
